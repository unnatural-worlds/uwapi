Uwapi
=====
UW api is an umbrella term for all user-generated content for the game Unnatural Worlds.

This document is the manual for making custom maps, mods, or writing custom ai/bots.

.. note::
	This document assumes familiarity with the base game.

.. important::
	All user-generated content requires full version of the game.
	It will not work with the Demo.

.. warning::
	Everything in this document is subject to change, as the game is still in development.
